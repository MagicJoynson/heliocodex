# Heliocodex

An interactive, data-driven atlas of the Sun and the planets, built on open NASA and JPL data. Phase 1 (MVP): a 3D solar system with live orbital positions and a detailed page for the Sun and each of the eight planets.

Roadmap: moons, then dwarf planets, asteroids and comets, then exoplanets.

## Stack

- [Astro](https://astro.build) (static output) and TypeScript
- [Three.js](https://threejs.org) for the 3D scenes
- Hosted on Cloudflare Pages

## Develop

```
npm install
npm run dev      # http://localhost:4321
npm run build    # static site in dist/
```

## Data

`src/data/facts.json` is generated by `scripts/build-facts.py` from:

- NASA NSSDC Planetary Fact Sheets (physical data)
- NASA/JPL SSD "Keplerian Elements for Approximate Positions of the Major Planets" (orbits, 1800 to 2050)

Run `npm run facts` to refresh it. The output is committed, so builds need no network. Editorial text is in `src/data/bodies.ts` and is written for this site.

Textures in `public/textures` are from Solar System Scope under CC BY 4.0.

## Cloudflare Pages settings

- Framework preset: Astro
- Build command: `npm run build`
- Build output directory: `dist`
- Node version: 22 (set `NODE_VERSION=22` if needed)
